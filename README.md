# 🚗 RideMate
### Campus Carpool Partner Matching System

**Making campus journeys easier through shared rides.**

RideMate is a campus-based carpool partner matching web application developed to connect student drivers with students looking for convenient and affordable transportation around **Marwadi University, Rajkot**.

The platform allows students to offer rides, discover available journeys, request seats and coordinate shared travel costs through a simple and user-friendly interface.

---

## 📌 Project Overview

Students often travel between university, hostels and nearby locations. RideMate provides a common platform where student drivers can share available seats and other students can find suitable rides.

The main goal is to make campus commuting more convenient while encouraging ride sharing and reducing individual travel costs.

## ✨ Key Features

- **Student Registration & Login** – Student account creation and login interface.
- **Student Dashboard** – Overview of rides, requests and travel activity.
- **Offer a Ride** – Drivers can publish journeys with available seats and fare per seat.
- **Find a Ride** – Search rides using pickup location, destination and date.
- **Seat Requests** – Students can request seats in available rides.
- **Request Management** – Drivers can accept or reject passenger requests.
- **Ride Management** – Drivers can manage, cancel and complete their rides.
- **Notifications** – View ride and request status updates.
- **Student Profile** – Manage personal and vehicle information.
- **RideMate Assistant** – Rule-based assistant for common platform-related questions.
- **Admin Dashboard** – Basic user, ride and report management interface.

## 🚀 Installation and Setup

### Prerequisites
- Node.js
- npm
- Git

### Steps

**1. Clone the repository**

```bash
git clone https://github.com/KTanzeelaMohammadi/RideMate.git
```

**2. Navigate to the project directory**

```bash
cd RideMate
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, usually:

`http://localhost:3000/`

## 💾 Data Storage and Security

This version of RideMate is a demonstration MVP. It uses browser localStorage for local data persistence.

It does not provide production-level authentication or server-side database security. A secure backend can be integrated in future versions.
